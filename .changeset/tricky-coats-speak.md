Show a 24-hour traffic chart for setups without query logs, using hourly total and blocked queries from Blocky's statistics API.

Enable [statistics](https://0xerr0r.github.io/blocky/latest/configuration/#statistics) in Blocky to use it. The history resets when Blocky restarts. Query logs still provide longer history and filtering.
